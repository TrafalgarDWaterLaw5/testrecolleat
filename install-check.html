Android installation check

This checks the files Chrome needs to install Recolleat as an app. It does not access, delete or modify your saved restaurants.

Checking installation setup…

What the results mean

If a check fails, the website files or deployment need repair. If every check passes but Android Chrome still reports “This app can't be installed”, the failure may be in Chrome's Android app-installation service, which a website cannot control.

Do not clear Chrome's site data or uninstall an existing Recolleat app. That can remove your locally stored journal. Keep a JSON backup before changing browser settings.

If installation fails, try another established installable web app in Chrome. If that also fails, the phone or Chrome installation service is a more likely cause.
